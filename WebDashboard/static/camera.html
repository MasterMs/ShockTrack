      Connection and camera help
      
Connect to the existing ShockTrack /ws endpoint, then start the camera. The address defaults to
        the server hosting this page. The camera selector switches between available cameras; Rotate changes the camera
        image in 90° steps.

      
Camera access requires HTTPS or http://localhost. Opening the dashboard through an HTTP LAN
        address can display sensor data while camera access remains unavailable. An HTTPS page requires a
        wss:// connection.
      

      
Recording saves a video download in this browser. Keep this tab visible while recording. CSV recording and
        cloud uploads are controlled separately.

      
Sensor values use the stream's native units. Predictions describe the model's current window; they are not
        ground-truth labels. The preview marks samples stale after 1.5 seconds without fresh data.
